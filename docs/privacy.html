Privacy policy

Updated October 25, 2026. Arty S. maintains the Vibe Coding Library website and public read-only MCP service. This notice covers the GitHub Pages catalog and use of that service. The separate offline package has its own privacy notice.

Website and browser preferences

Catalog filtering runs in your browser. Full-text search downloads a public instruction index. Search terms and filters can appear in URLs, browser history and shared links, and may be included in page requests or referrer information received by the hosting provider. Keep confidential information out of searches and shared URLs.

The website stores your assistant choice and workflow-prompt language in local storage, using the keys vibe-coding-host and vibe-coding-language. Website JavaScript uses these preferences locally. You can change them with the controls or remove them by clearing browser storage. Copy buttons write the requested prompt or connection URL to your clipboard. The catalog code adds no analytics or tracking cookies.

Public MCP service

The MCP service receives the arguments needed for search and retrieval: technical keywords, workflow or domain identifiers, task, result language, optional host preference and pagination. It returns public instructions and does not request access to your repository, connected accounts or local files. Do not send source code, credentials, personal data or confidential information in tool requests.

The application searches a public library in memory. It does not create user accounts or save a query history. Application error logs identify the tool or HTTP status and request duration; they exclude arguments and results. Details are in the MCP service privacy policy.

Hosting and other services

GitHub Pages hosts the catalog. The MCP service is hosted through OpenAI Sites on Cloudflare infrastructure. These hosting and security providers may process IP addresses, HTTP request metadata and traffic to deliver and protect their services. Their processing and log retention follow their own policies: GitHub, OpenAI and Cloudflare. This notice does not set their retention periods.

Your coding assistant or MCP client processes prompts, files and responses under its own settings and policies. Connecting the library does not give the service the agent's project permissions.

Support and privacy questions

Information you post in GitHub issues or pull requests is public and handled by GitHub. Do not post private source code, credentials or personal data. For private support or privacy questions, contact artemsatsuk@proton.me. Support messages are handled through the provider used to send them and its policies.
