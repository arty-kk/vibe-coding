Приватность

Vibe Coding поддерживает Arty S. / ARTSIOM SATSUK (arty-kk).

Плагин содержит текстовые инструкции, локальный каталог и локальные утилиты Python. У него нет серверной части под управлением издателя, аналитики, пикселей отслеживания, cookies, системы аккаунтов или телеметрии. Утилиты каталога и упаковки не передают содержимое проектов издателю.

При использовании плагина в Codex, ChatGPT или Claude приложение обрабатывает запросы, файлы и результаты инструментов согласно своим настройкам и политикам. Сценарии могут использовать инструменты и сервисы, включённые пользователем; эти сервисы применяют собственные политики обработки данных. Плагин не выдаёт себе дополнительные разрешения.

Публичный сайт размещён на GitHub Pages. GitHub может обрабатывать обычную информацию о запросах согласно своей политике конфиденциальности. Информация, добровольно опубликованная в issues или pull requests репозитория, общедоступна и обрабатывается GitHub. Не публикуйте учётные данные, закрытый исходный код или персональные данные.

Сайт и офлайн-каталог сохраняют только выбранные язык и ассистента в локальном хранилище браузера. Эти настройки не передаются издателю.

Вопросы о приватности можно задать в GitHub Issues, не указывая конфиденциальных сведений.
