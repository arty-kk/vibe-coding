Algunos detalles útiles

¿Qué es Vibe Coding?

Vibe Coding es un plugin de código abierto con 46 habilidades y 241 flujos para Codex y Claude Code. Abarca revisión de código, depuración, bases de datos, accesibilidad, infraestructura e IA. Cada flujo define el alcance, los pasos, las pruebas que recopilar y las comprobaciones de la tarea.

¿Cómo utilizo un flujo?

Instala el plugin, abre un flujo y copia su prompt para Codex o Claude Code. Añade los archivos, el comportamiento o el cambio en el que quieres trabajar.

¿Qué idiomas admite?

La web y los prompts están en inglés, español, ruso y chino simplificado. Las instrucciones técnicas están escritas en inglés; puedes pedirle al asistente que responda en tu idioma.

¿Necesita una cuenta o clave API propia?

No. Utiliza las herramientas y los permisos de tu asistente. No incluye servidores, servicios en segundo plano ni telemetría.
