Un flujo que sigue tu intención

Cada habilidad selecciona instrucciones específicas. El asistente sigue el código relevante, identifica dónde se define el contrato y comprueba el comportamiento afectado. Las recetas detalladas se cargan cuando hacen falta.

Inspeccionar

Pide una auditoría o revisión para obtener pruebas, impacto y un siguiente paso concreto. El código del producto no se modifica.

Implementar

Pide una corrección o mejora para autorizar el cambio pertinente, incluidos los consumidores y contratos afectados.

Verificar

Comprueba el comportamiento solicitado y distingue lo que pasó, falló o no pudo probarse. Una comprobación acotada no certifica todo el proyecto.

Empieza con una tarea real de ingeniería

Explorar un repositorio ↗

Sigue la API, los responsables de los datos y la ejecución antes de trabajar en código desconocido.

Revisar un cambio ↗

Inspecciona el cambio completo y sus dependencias directas para encontrar defectos corregibles.

Depurar un fallo ↗

Rastrea un error reproducible hasta su origen, corrige la causa y ejecuta una comprobación útil.

Comprobar una versión ↗

Compara las pruebas de la versión con los controles exigidos e identifica lo que falta.

Instalar el plugin

Las mismas 46 habilidades funcionan en ambos asistentes. Elige el que usas para trabajar con repositorios.

Codex

Instala Vibe Coding desde el directorio de plugins de OpenAI y empieza una tarea nueva.

Abrir el directorio de Codex ↗

$vibe Map this repository and explain its main contracts.

Claude Code

Añade este marketplace público de GitHub e instala el plugin en Claude Code:

claude plugin marketplace add arty-kk/vibe-coding
claude plugin install vibe-coding@vibe-coding

Abre una sesión nueva de Claude Code e invoca una habilidad con el prefijo del plugin:

/vibe-coding:vibe Map this repository and explain its main contracts.

Acerca de Vibe Coding

¿Qué añade Vibe Coding a mi asistente?

Añade instrucciones de ingeniería: una habilidad de entrada, habilidades por área y recetas específicas. Cubren producto, API, datos, seguridad, infraestructura, funciones de IA, MCP, renderizado web y comprobaciones de versiones. No añade un motor de ejecución ni un modelo.

¿En qué se diferencia de un único prompt?

Una habilidad elige primero el área y la operación. Una receta define después el objetivo, las restricciones, las invariantes de ingeniería y el método de verificación. El flujo compartido distingue inspección, implementación y comprobación.

¿El plugin ejecuta servicios o recopila datos?

No instala servidores MCP, servicios en segundo plano, conexiones de cuentas ni telemetría. El asistente usa sus herramientas y permisos existentes. La web no utiliza analítica ni scripts de terceros; el almacenamiento local del navegador recuerda las preferencias del catálogo.

¿Puedo usarlo con Claude?

Esta versión incluye el manifiesto para Claude Code y un marketplace público. Las habilidades se invocan como /vibe-coding:nombre-de-habilidad. La instalación documentada está orientada al trabajo con repositorios en Claude Code; otras interfaces de Claude dependen de su soporte de plugins.

¿Qué idiomas admite?

El catálogo, las etiquetas de búsqueda y los prompts admiten inglés, español, ruso y chino simplificado. Las instrucciones técnicas están en inglés. Puedes pedir al asistente que responda en tu idioma.

¿Garantiza que el código sea correcto?

No. El resultado depende del modelo, el contexto, las herramientas y las comprobaciones disponibles. Los flujos exigen pruebas y distinguen resultados observados, suposiciones y comprobaciones bloqueadas. Revisa los cambios antes de utilizarlos.
