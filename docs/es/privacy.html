Política de privacidad

Actualizado el 25 de octubre de 2026. Arty S. mantiene el sitio web de Vibe Coding Library y el servicio MCP público de solo lectura. Este aviso cubre el catálogo de GitHub Pages y el uso del servicio. El paquete sin conexión, disponible por separado, tiene su propio aviso de privacidad.

Sitio web y preferencias del navegador

Los filtros del catálogo se aplican en tu navegador. La búsqueda de texto completo descarga un índice público de instrucciones. Los términos y filtros pueden aparecer en las URL, el historial y los enlaces compartidos, y pueden incluirse en las peticiones o la información de referencia que recibe el proveedor de alojamiento. No incluyas información confidencial en las búsquedas ni en las URL compartidas.

La web guarda el asistente elegido y el idioma de los prompts en el almacenamiento local, con las claves vibe-coding-host y vibe-coding-language. El JavaScript de la web usa estas preferencias localmente. Puedes cambiarlas con los controles o eliminarlas borrando el almacenamiento del navegador. Los botones de copia escriben el prompt o la URL de conexión solicitados en el portapapeles. El código del catálogo no añade analítica ni cookies de seguimiento.

Servicio MCP público

El servicio MCP recibe los argumentos necesarios para buscar y recuperar instrucciones: palabras clave técnicas, identificadores de flujo o área, tarea, idioma de los resultados, preferencia opcional de asistente y paginación. Devuelve instrucciones públicas y no solicita acceso a tu repositorio, cuentas conectadas ni archivos locales. No envíes código fuente, credenciales, datos personales ni información confidencial en las peticiones.

La aplicación busca en una biblioteca pública en memoria. No crea cuentas de usuario ni guarda un historial de consultas. Los registros de errores de la aplicación identifican la herramienta o el estado HTTP y la duración de la petición; excluyen los argumentos y resultados. Consulta la política de privacidad del servicio MCP.

Alojamiento y otros servicios

GitHub Pages aloja el catálogo. El servicio MCP se aloja mediante OpenAI Sites en infraestructura de Cloudflare. Estos proveedores de alojamiento y seguridad pueden tratar direcciones IP, metadatos de peticiones HTTP y tráfico para prestar y proteger sus servicios. El tratamiento y la conservación de sus registros siguen sus propias políticas: GitHub, OpenAI y Cloudflare. Este aviso no fija sus plazos de conservación.

Tu asistente de programación o cliente MCP trata prompts, archivos y respuestas según sus propios ajustes y políticas. Conectar la biblioteca no concede al servicio los permisos del agente sobre el proyecto.

Soporte y consultas de privacidad

Lo que publiques en GitHub Issues o pull requests es público y lo gestiona GitHub. No publiques código privado, credenciales ni datos personales. Para consultas privadas de soporte o privacidad, escribe a artemsatsuk@proton.me. Los mensajes de soporte se tramitan mediante el proveedor usado para enviarlos y sus políticas.
