Privacidad

Vibe Coding es mantenido por Arty S. / ARTSIOM SATSUK (arty-kk).

El plugin distribuido contiene instrucciones de texto, un catálogo local y utilidades locales de Python. No tiene backend operado por el editor, analítica, píxeles de seguimiento, cookies, sistema de cuentas ni telemetría. Las utilidades de catálogo y empaquetado no envían el contenido de los proyectos al editor.

Cuando se usa el plugin en Codex, ChatGPT o Claude, la aplicación anfitriona procesa prompts, archivos y resultados de herramientas según su configuración y sus políticas. Los flujos de trabajo pueden usar herramientas y servicios que el usuario haya habilitado; esos servicios aplican sus propias políticas de datos. El plugin no se concede permisos adicionales.

El sitio web público está alojado en GitHub Pages. GitHub puede procesar información habitual de las solicitudes según su política de privacidad. La información publicada voluntariamente en issues o pull requests del repositorio es pública y la gestiona GitHub. No publiques credenciales, código fuente privado ni datos personales.

El sitio web y el catálogo sin conexión guardan únicamente el idioma y el asistente seleccionados en el almacenamiento local del navegador. Estas preferencias no se envían al editor.

Puedes plantear preguntas sobre privacidad en GitHub Issues sin incluir información sensible.
