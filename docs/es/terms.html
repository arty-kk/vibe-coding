Condiciones del servicio

Actualizado el 25 de octubre de 2026. El sitio web de Vibe Coding Library y el servicio MCP público ofrecen flujos e instrucciones de ingeniería. Arty S. mantiene el proyecto. El código fuente y la biblioteca de flujos están disponibles bajo la licencia MIT.

Uso de las instrucciones

El servicio busca y devuelve instrucciones públicas. No inspecciona, edita, despliega, paga ni elimina nada en tu entorno. Tu agente aplica las instrucciones con sus propias herramientas y permisos. Tú decides si el flujo es adecuado, autorizas las acciones en el proyecto y compruebas los cambios resultantes.

No incluyas credenciales, datos personales ni código confidencial en búsquedas, URL de búsqueda compartidas o peticiones MCP. Consulta las condiciones del servicio MCP y su política de privacidad para conocer el alcance declarado del servicio.

Coste, disponibilidad y terceros

La biblioteca pública se ofrece gratis y no requiere cuenta del editor, suscripción ni clave de API. El asistente, el proveedor del modelo y los servicios externos que elijas usar siguen sujetos a sus propias condiciones y a los cargos que correspondan.

El software y el servicio se proporcionan tal cual, sin garantías, conforme a la licencia MIT. No se garantizan la disponibilidad, la integridad ni la idoneidad para una tarea concreta. Las versiones, enlaces al código y hashes devueltos identifican las instrucciones utilizadas.

El paquete Vibe Coding sin conexión es una distribución opcional y separada con sus propias condiciones.

Soporte

Informa de defectos reproducibles en GitHub Issues. Envía consultas privadas de soporte o privacidad a artemsatsuk@proton.me. El soporte se ofrece según la disponibilidad del mantenedor.
