隐私政策

更新于 2026 年 10 月 25 日。Arty S. 维护 Vibe Coding Library 网站和公共只读 MCP 服务。本政策涵盖 GitHub Pages 目录及该服务的使用。单独提供的离线软件包有自己的隐私说明。

网站与浏览器偏好设置

目录筛选在浏览器中运行，全文搜索会下载公共说明索引。搜索词和筛选条件可能出现在 URL、浏览器历史记录和分享的链接中，也可能包含在托管提供方收到的页面请求或来源信息中。请勿在搜索和分享链接中填写机密信息。

网站使用本地存储中的 vibe-coding-host 和 vibe-coding-language 键，保存助手选择和工作流提示词语言。网站 JavaScript 在本地使用这些偏好设置。你可以在界面中修改，或通过清除浏览器存储来移除。复制按钮会将所请求的提示词或连接 URL 写入剪贴板。目录代码不添加分析功能或跟踪 Cookie。

公共 MCP 服务

MCP 服务接收搜索和获取说明所需的参数：技术关键词、工作流或领域 ID、任务、结果语言、可选的助手偏好及分页参数。服务返回公共说明，不请求访问你的代码仓库、已连接账户或本地文件。请勿在工具请求中发送源代码、凭据、个人信息或机密信息。

应用在内存中搜索公共工作流库，不创建用户账户或保存查询历史。应用错误日志记录工具名称或 HTTP 状态及请求时长，不包含参数或结果。详情请参阅 MCP 服务隐私政策。

托管及其他服务

目录托管在 GitHub Pages 上，MCP 服务通过 OpenAI Sites 在 Cloudflare 基础设施上运行。托管和安全服务提供方可能处理 IP 地址、HTTP 请求元数据及流量，以提供和保护服务。其处理方式和日志保留期限由各自的政策规定：GitHub、OpenAI 和 Cloudflare。本政策不规定这些提供方的保留期限。

编程助手或 MCP 客户端按照自身设置和政策处理提示词、文件及响应。连接工作流库不会将智能体的项目权限授予该服务。

支持与隐私咨询

你在 GitHub Issues 或拉取请求中发布的信息是公开的，由 GitHub 处理。请勿发布私有源代码、凭据或个人信息。私人支持或隐私问题请联系 artemsatsuk@proton.me。支持消息的处理取决于发送消息所用的提供方及其政策。
