工作流库如何运作

什么是 Vibe Coding Library？

这是提供 241 个工程工作流的公共只读 MCP 工作流库。兼容的智能体通过 search_workflows 搜索，再通过 get_workflow 获取所选说明。Codex 和 Claude Code 有现成的插件配置，其他智能体可连接相同端点。

哪些智能体可以连接？

使用支持通过 Streamable HTTP 访问远程 MCP 服务器的编程智能体或客户端。添加公共端点，并将身份验证设为无。工作流库不需要专用 API 密钥，智能体或模型提供方可能有各自的设置要求。

两个工具分别做什么？

search_workflows 返回工作流标题、摘要和稳定 ID。get_workflow 加载所选步骤的说明。智能体通过自身项目工具应用说明，并保留后续步骤需要的上下文。

支持哪些语言？

网站、目录信息和提示词支持英语、西班牙语、俄语及简体中文。技术说明保留英语。你可以要求智能体用你的语言回答。

需要账户或 API 密钥吗？

不需要。公共 MCP 端点通过 Streamable HTTP 提供服务，无需身份验证。连接需要网络，返回公共说明，不能读取或修改你的代码仓库。智能体和模型提供方的账户与密钥需单独配置。

可以离线使用完整工作流库吗？

可以。原版 Vibe Coding 是面向 Codex 和 Claude Code 的独立可选插件，包含 46 个本地技能和全部 241 个工作流。其原生命令与通用 MCP 连接方式不同。
