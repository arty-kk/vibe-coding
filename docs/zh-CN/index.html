你可能还想了解

插件包含什么？

46 项技能和 241 个工作流，涵盖 API 审查、数据库检查、无障碍、基础设施及 AI 功能。每个工作流都提供操作步骤和验证方法。

如何使用工作流？

安装插件后，打开所需工作流，复制适用于 Codex 或 Claude Code 的提示词，并补充文件、问题描述或需要处理的变更。

支持哪些语言？

网站和提示词支持英语、西班牙语、俄语和简体中文。技术指令以英文编写；你可以要求助手用你偏好的语言回答。

需要单独的账户或 API 密钥吗？

不需要。插件使用助手现有的工具和权限，没有自己的服务器、后台服务或遥测。
