# Web offer & page strategy

Apply [the working contract](../../references/workflow.md) once. Work from the actual offer, visitors and intended next action. These planning workflows prepare a buildable website proposal; they do not change product code or publish a site.

| Needed result | Current prompt |
|---|---|
| Turn scattered product material into a clear offer, proof and conversion brief | [Web Offer Synthesis](references/web-offer-synthesis.md) |
| Choose and order page sections, interaction modules and conversion paths | [Web Page Architecture](references/web-page-architecture.md) |

For a complete proposal, pass the offer brief into page architecture, then [Website Copy & Microcopy](../vibe-content/references/web-page-copy.md), [Web Reference Research](../vibe-web-art-direction/references/web-reference-research.md), [Web Art Direction](../vibe-web-art-direction/references/web-art-direction.md), [Web Visual System](../vibe-web-art-direction/references/web-visual-system.md), [Web Interaction Storyboard](../vibe-web-art-direction/references/web-interaction-storyboard.md), [Web Project Architecture](../vibe-landing/references/web-project-architecture.md) and [Web Experience Brief](../vibe-landing/references/web-experience-brief.md). Load each prompt only when its inputs are ready; retain previous decisions instead of asking the same questions again.

Start at the missing stage when useful inputs already exist. A campaign landing page may have one conversion goal; a multi-audience homepage may need several clear destination paths with a primary emphasis. Choose the appropriate model rather than forcing either into the other.

Retain the user's explicit requirements in a compact ledger with stable IDs, the requested outcome, its owning stage and eventual acceptance evidence. Carry it through every handoff alongside the offer and unresolved facts. Distinguish required outcomes from conditional suggestions. Add the applicable website foundations—navigation, content, identity, visual/interaction system, responsive behavior, architecture, search and loading—without inventing business features. The final brief reconciles this ledger with actual decisions and artifacts; changing a later section plan does not silently remove a requirement.

Preserve a supplied brand, language, audience, content, funnel and scope. Resolve ordinary choices from evidence and state consequential assumptions. Ask for facts that change the offer or commitment; do not invent prices, customers, testimonials, availability or business results. The next stage must receive the actual proof inventory and unresolved decisions alongside the creative brief.
