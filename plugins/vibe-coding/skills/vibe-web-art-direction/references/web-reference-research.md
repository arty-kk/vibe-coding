# Web Reference Research

## Goal

Build a compact, inspectable reference and asset brief for the actual offer and page architecture. Extract useful design mechanisms and verify usable source material so the next stage can create an original direction with credible graphics and feasible interactions.

## Research method

Start from supplied references, brand constraints, section jobs and existing assets. Identify what is missing: composition, typographic character, material treatment, imagery, a functional module, mobile behavior or a motion technique. Select a small, complementary reference set that answers those gaps. A page with a similar audience may inform narrative; an unrelated product may still offer a useful typographic or interaction principle.

Open the actual reference where tools permit. Record its URL, the region or interaction observed and the transferable decision. Inspect the complete composition as well as a detail. For a responsive or animated idea, observe the relevant viewport or interaction; a screenshot establishes appearance at one moment, not timing, keyboard behavior or mobile suitability. If only source text, still images or an inaccessible preview are available, distinguish that evidence from the proposed treatment. Never present an unvisited reference as visually inspected.

For each selected reference, write **observed mechanism → why it suits this page → adaptation → limits**. Useful mechanisms include an editorial scale change, a demonstrated product behavior, an image crop, a comparison pattern, a material edge, a scroll-linked transition or a distinctive navigation rhythm. Preserve the user's own identity; do not transfer another site's logo, wording, proprietary illustration or entire composition as a new brand.

## Asset selection

Inventory available project material before searching or generating replacements. Prefer actual product, people, work, space and process where the claim depends on them. Specify the role of each image, icon, video, typeface, illustration or 3D object: what it communicates, placement, framing, variants, alternative text or decorative status, source/license and what is still missing. Distinguish “source located”, “downloaded”, “inspected” and “ready for use”. An asset count or remote link does not establish visual suitability or a right to reuse it.

Choose a coherent icon family by silhouette, stroke/fill, optical size and semantic fit. Verify that the needed icons exist. Plan a custom mark or illustration when an important concept has no good icon; unrelated pictograms do not explain a product. Preserve multilingual font coverage and required weights when selecting a real typeface.

For depth, compare real photography, layered composition, CSS/SVG forms, pre-rendered media and an interactive 3D scene. Use an actual model or image source when representing a real object. A proposed render needs a scene/material/camera brief; it must not masquerade as a photograph of the user's product. Record the expected bytes, device cost and fallback before selecting a heavy format or renderer.

For procedural or algorithmic references, identify the underlying family—flow field, contour, halftone, grid, noise, refraction, particle system or lighting—and the parameters that make it appropriate. Inspect whether its bright or dense phases cross reading areas. Specify a quiet region, clipping/underlay, palette, scale, seed, speed, affected section and static/reduced-motion form. Collections such as [getdesign.md backgrounds](https://getdesign.md/backgrounds) can inform this research; public previews do not imply access to the supplied commercial component source.

## Result and handoff

Return the reference matrix, an asset manifest with evidence/status and source constraints, and a shortlist of techniques tied to actual sections. Explain which patterns are useful, which do not fit this offer, and which require a prototype. Include direct source links; do not fill the document with unannotated inspiration images.

Pass the brief into **Web Art Direction**. Missing production assets need an acquisition or production task and a truthful interim treatment; they do not justify fabricated evidence. Reference research alone does not authorize purchases, subscriptions, asset uploads or publication.
