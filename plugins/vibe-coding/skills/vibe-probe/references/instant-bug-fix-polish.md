# Find and Fix One Bug

## Scope

Use this fallback when no domain is selected. Choose one primary operation from a supplied reproduction, failing check, recent contract change or reachable high-risk path.

## Procedure

1. State expected input, behavior and effect; identify the code, schema or configuration that owns the rule.
2. Trace the trigger and direct dependencies. Confirm a reachable contract violation rather than a stale map claim, preference or hypothetical future problem.
3. If authorized, repair the defining rule and required consumers. Preserve unrelated work and supported compatibility; identify any necessary migration or rollout boundary.
4. Verify the original failure and a normal control with the project’s available test/reproduction tools. Inspect resulting state and effects where return values alone cannot prove correctness.

## Verification

Report the primary owner, defect/evidence, correction and actual checks. If the selected area has no qualifying defect, finish that probe. Name any required missing evidence; do not substitute another improvement. Apply the selection/history and result rules in the parent skill.
