# Privacy

Vibe Coding is maintained by Arty S. ([arty-kk](https://github.com/arty-kk)).

The distributed plugin contains text instructions, a local catalog and local Python utilities. It has no publisher-operated backend, analytics, tracking pixels, cookies, account system or telemetry. Its catalog and packaging utilities do not send project contents to the publisher.

When the plugin is used in Codex or ChatGPT, the host processes prompts, files and tool results under the host's settings and policies. Workflows may use tools and services that the user has enabled; those services apply their own data policies. The plugin does not grant itself additional permissions.

The public website is hosted on GitHub Pages. GitHub may process ordinary request information under its privacy policy. Information voluntarily posted in repository issues or pull requests is public and handled by GitHub. Do not post credentials, private source code or personal data.

Privacy questions can be raised at [https://github.com/arty-kk/vibe-coding/issues](https://github.com/arty-kk/vibe-coding/issues) without including sensitive details.
